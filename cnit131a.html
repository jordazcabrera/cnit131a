CNIT-131A – XML and JSON Assignments

  • Homework 1
    Introduction to XML basics and structure.

    XML is used to store data using tags. It has one main root element, and all tags must be properly opened and closed. Attributes can be used to add extra information.

  • Homework 2
    Working with XML and JSON files and validating data

    XML and JSON store data, and validating ensures the file has the correct structure.

  • Homework 3
    XSL Transformation

    XSLT turns XML data into a formatted web page using styles and XPath.

  • Homework 4
    XPath Expression

    XPath lets you extract, count, and format XML data dynamically using XSLT.

  • Homework 5
    Document Type Definition (DTD)

    A Document Type Definition (DTD) defines the structure and rules of an XML document, ensuring it is valid, consistent, and properly organized.

  • Homework 6
    XML Schema

    XML Schema defines the structure and data types of an XML document, allowing it to be validated against a set of rules.
